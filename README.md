# SpendWise

SpendWise is a simple personal budget and expense tracker website.

## What I Built

### Add Expense Form
The form allows the user to enter an expense name and amount and select a category from a dropdown list.

### Expense Table
The table displays sample expenses with their name, amount, category, and date.

### Multimedia
The website includes a budget-related SVG image and a budgeting tips YouTube video.

### CSS Styling
CSS is used to style the page, form, table, alternating rows, hover effects, and input focus effects.

### Interactive Features
The website includes an Add Expense button, table hover effects, and a collapsible "How to use SpendWise" section.

## Technologies Used

- HTML
- CSS
